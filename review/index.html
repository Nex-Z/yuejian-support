《雨后渡口》示例书源

这篇原创短篇共两章。两个示例来源提供同一部作品，可以体验搜索、换源和离线阅读。

下载书源 JSON在线试读

在阅见中打开

  1. 下载上面的文件，在阅见「发现 → 导入书源」选择 JSON 文件并确认导入。也可以长按书源链接复制地址，在「链接导入」中粘贴。
  2. 从书架右上角搜索「雨后渡口」。打开详情，在「书籍来源 → 换源」查看两个示例来源。
  3. 开始阅读后，点正文中央，再点「更多 → 下载与缓存 → 下载未缓存章节」。保持前台直至下载完成，断开网络后从目录打开第二章。

Try the sample sources

Download the source file and import it from Discovery (发现 → 导入书源). Search for 雨后渡口 from the Bookshelf. Open the result and use 换源 to choose between sources A and B. Both serve the same original two-chapter story.

To test offline reading, open the book and tap its center. Choose 更多 → 下载与缓存 → 下载未缓存章节 and keep the app in the foreground until it finishes. Turn off the network and open chapter two from 目录.
