隐私政策

更新于 2026 年 11 月 21 日 · English

本机阅读

阅见无需注册。书架、导入的书籍、阅读进度、书签、搜索历史、阅读设置和书源配置保存在设备上。阅见未集成广告或第三方行为分析服务。

在线书源

当你通过链接导入书源、搜索、查看发现分类、换源、加载封面、阅读或下载在线章节时，设备会向相应网站发送请求。全源搜索会将输入的关键词发给参与搜索的各个书源。请求还可能包含书籍或章节地址、规则生成的参数。接收网站可以看到网络地址，并按其政策处理请求。请仅导入信任且有权使用的书源。可在书源管理中停用来源。

相机

扫码导入时，阅见会请求相机权限并在设备上识别二维码。扫码画面不会由阅见保存或上传；识别出的导入链接用于访问相应网站。你可以在系统设置中关闭相机权限，也可以直接导入文件。

备份

开启「我的 → 数据管理 → iCloud 备份」后，阅见会将书架、进度、书签、书源配置、搜索历史和设置等保存到你的 iCloud。开启「包含本地 TXT／EPUB」后，备份还会包含已导入的本地正文。阅见的这项备份不含下载的章节缓存和漫画图片。关闭开关会停止后续自动备份。已有云端数据可通过系统的 iCloud 储存空间管理；你另行保存的备份文件可在其保存位置删除。

保留与删除

本地数据会保留供后续阅读。可在书架中删除书籍，在「我的」中管理书签、书源与下载缓存，在搜索页清除历史。移出书架只改变归属。删除 App 会移除该安装的本机数据，已有的系统备份和 iCloud 数据需另行管理。

本网站与支持邮件

本网站与《雨后渡口》示例书源由 GitHub Pages 托管。GitHub 会为安全目的记录并保存访问者的 IP 地址。本站的示例书源始终读取同一份目录，仅在网址片段中使用搜索词；该片段不会随 HTTP 请求发送给 GitHub。本站未添加广告、第三方统计、外部字体或反馈表单。

如果你主动发邮件，我们会收到邮件地址、正文及你选择发送的附件，用于回复和处理问题。可发送邮件要求删除此前提供的支持材料。联系开发者：2657272578@qq.com。GitHub 隐私声明

Privacy policy

Updated November 21, 2026.

Yuejian requires no account. Imported books, your shelf, progress, bookmarks, search history, reading settings and source definitions are stored on your device. The app has no ads or third-party behavioral analytics.

When you import a link, search, switch sources, browse categories, load covers or download chapters, your device contacts the relevant sites. All-source search sends the query to each participating source. Requests may include book or chapter URLs and parameters generated by source rules. Sites can see your IP address and process requests under their own policies. You can disable sources in source management.

QR scanning uses the camera to recognize codes on your device. Yuejian does not save or upload the camera image. It uses the recognized link to fetch the source. You can turn off camera access in iOS Settings or import a file instead.

If you enable iCloud backup, the app backs up your shelf, progress, bookmarks, source definitions, search history and settings to your iCloud. Parsed local text is included when you enable the TXT/EPUB option. Downloaded chapter caches and comic images are excluded from this app backup. Turning backup off stops future automatic backups. Manage existing cloud data in iCloud storage settings and delete separately saved backup files from their saved locations.

You can delete books, manage bookmarks and source definitions, clear downloaded chapters, or clear search history. Removing a book from the shelf changes shelf membership only. Deleting the app removes its local installation data. Existing system backups and iCloud data are managed separately.

GitHub Pages hosts this site and the sample sources. GitHub logs visitor IP addresses for security. The sample sources load a fixed catalogue. The search term is placed in a URL fragment, which is not sent to GitHub in the HTTP request. This site adds no ads, analytics or external fonts.
